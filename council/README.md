# Model Council

This folder stores recommendations from AI models. These are opinions, not authoritative decisions.

Files:
- `chatgpt-opinions.md`
- `claude-opinions.md`
- `gemini-opinions.md`
- `codex-opinions.md`

## Rule
A model opinion may influence planning, but it becomes authoritative only after Amir explicitly approves it and the decision is copied to `decisions/APPROVED_DECISIONS.md`.

Each opinion should include date, model, project, recommendation, rationale, evidence level, and status (`open`, `accepted`, `rejected`, `superseded`).
